## GET /api/users — Obtener usuarios

Retorna la lista completa de usuarios registrados. Admite paginación mediante parámetros de consulta.

<Note>
  **Autenticación requerida.** Incluye el token Bearer en el header `Authorization`.
</Note>

**URL de la petición**
```
GET https://api.example.com/api/users
```

**Headers**

| Header | Valor | Obligatorio |
|--------|-------|-------------|
| `Authorization` | `Bearer {token}` | ✅ Sí |
| `Accept` | `application/json` | ✅ Sí |

**Parámetros de consulta (Query Parameters)**

<ParamField query="page" type="integer">
  Número de página. Por defecto: `1`.
</ParamField>

<ParamField query="per_page" type="integer">
  Número de resultados por página. Por defecto: `15`. Máximo: `100`.
</ParamField>

<ParamField query="search" type="string">
  Filtra usuarios por nombre o correo electrónico.
</ParamField>

**Respuesta exitosa — 200 OK**

```json Respuesta
{
  "status": "success",
  "data": [
    {
      "id": 1,
      "name": "Ana García",
      "email": "ana.garcia@example.com",
      "role": "admin",
      "created_at": "2024-01-15T10:30:00Z"
    },
    {
      "id": 2,
      "name": "Carlos López",
      "email": "carlos.lopez@example.com",
      "role": "user",
      "created_at": "2024-02-20T14:45:00Z"
    }
  ],
  "pagination": {
    "current_page": 1,
    "per_page": 15,
    "total": 87,
    "last_page": 6
  }
}
```

**Códigos de error**

| Código | Descripción |
|--------|-------------|
| `401 Unauthorized` | Token no proporcionado o inválido |
| `403 Forbidden` | No tienes permisos para listar usuarios |
| `500 Internal Server Error` | Error interno del servidor |

**Ejemplos de código**

<CodeGroup>

```php GET /api/users — PHP
<?php

$token = 'tu_token_aqui';

$ch = curl_init();
curl_setopt_array($ch, [
    CURLOPT_URL            => 'https://api.example.com/api/users?page=1&per_page=15',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => [
        'Authorization: Bearer ' . $token,
        'Accept: application/json',
    ],
]);

$response = curl_exec($ch);
$statusCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

$data = json_decode($response, true);
print_r($data);
```

```javascript GET /api/users — JavaScript
const token = 'tu_token_aqui';

const response = await fetch(
  'https://api.example.com/api/users?page=1&per_page=15',
  {
    method: 'GET',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Accept': 'application/json',
    },
  }
);

if (!response.ok) {
  throw new Error(`HTTP error: ${response.status}`);
}

const data = await response.json();
console.log(data);
```

```python GET /api/users — Python
import requests

token = 'tu_token_aqui'

headers = {
    'Authorization': f'Bearer {token}',
    'Accept': 'application/json',
}

params = {
    'page': 1,
    'per_page': 15,
}

response = requests.get(
    'https://api.example.com/api/users',
    headers=headers,
    params=params,
)

response.raise_for_status()
data = response.json()
print(data)
```

```bash GET /api/users — cURL
curl -X GET \
  'https://api.example.com/api/users?page=1&per_page=15' \
  -H 'Authorization: Bearer tu_token_aqui' \
  -H 'Accept: application/json'
```

</CodeGroup>

## POST /api/users — Crear usuario

Crea un nuevo usuario en el sistema. Devuelve el objeto del usuario creado con su ID asignado.

<Note>
  **Autenticación requerida.** Solo usuarios con rol `admin` pueden crear nuevos usuarios.
</Note>

**URL de la petición**
```
POST https://api.example.com/api/users
```

**Headers**

| Header | Valor | Obligatorio |
|--------|-------|-------------|
| `Authorization` | `Bearer {token}` | ✅ Sí |
| `Content-Type` | `application/json` | ✅ Sí |
| `Accept` | `application/json` | ✅ Sí |

**Parámetros del cuerpo (Body Parameters)**

<ParamField body="name" type="string" required>
  Nombre completo del usuario. Mínimo 2 caracteres, máximo 100.
</ParamField>

<ParamField body="email" type="string" required>
  Correo electrónico único del usuario. Debe ser un email válido.
</ParamField>

<ParamField body="password" type="string" required>
  Contraseña del usuario. Mínimo 8 caracteres. Debe incluir letras y números.
</ParamField>

<ParamField body="role" type="string">
  Rol del usuario. Valores: `admin`, `user`. Por defecto: `user`.
</ParamField>

<ParamField body="phone" type="string">
  Número de teléfono del usuario. Formato: `+34 600 000 000`.
</ParamField>

**Cuerpo de la petición**

```json Cuerpo JSON
{
  "name": "María Fernández",
  "email": "maria.fernandez@example.com",
  "password": "SecurePass123",
  "role": "user",
  "phone": "+34 611 222 333"
}
```

**Respuesta exitosa — 201 Created**

```json Respuesta
{
  "status": "success",
  "message": "Usuario creado correctamente",
  "data": {
    "id": 42,
    "name": "María Fernández",
    "email": "maria.fernandez@example.com",
    "role": "user",
    "phone": "+34 611 222 333",
    "created_at": "2024-04-10T12:00:00Z"
  }
}
```

**Códigos de error**

| Código | Descripción |
|--------|-------------|
| `400 Bad Request` | Datos inválidos o incompletos en el cuerpo |
| `401 Unauthorized` | Token no proporcionado o inválido |
| `403 Forbidden` | No tienes permisos para crear usuarios |
| `409 Conflict` | Ya existe un usuario con ese correo electrónico |
| `422 Unprocessable Entity` | Error de validación en los campos enviados |
| `500 Internal Server Error` | Error interno del servidor |

**Ejemplos de código**

<CodeGroup>

```php POST /api/users — PHP
<?php

$token = 'tu_token_aqui';

$body = [
    'name'     => 'María Fernández',
    'email'    => 'maria.fernandez@example.com',
    'password' => 'SecurePass123',
    'role'     => 'user',
    'phone'    => '+34 611 222 333',
];

$ch = curl_init();
curl_setopt_array($ch, [
    CURLOPT_URL            => 'https://api.example.com/api/users',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST           => true,
    CURLOPT_POSTFIELDS     => json_encode($body),
    CURLOPT_HTTPHEADER     => [
        'Authorization: Bearer ' . $token,
        'Content-Type: application/json',
        'Accept: application/json',
    ],
]);

$response = curl_exec($ch);
$statusCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

$data = json_decode($response, true);
print_r($data);
```

```javascript POST /api/users — JavaScript
const token = 'tu_token_aqui';

const body = {

```

## PUT /api/users/{id} — Actualizar usuario

Actualiza los datos de un usuario existente. Puedes enviar solo los campos que deseas modificar (actualización parcial).

<Note>
  **Autenticación requerida.** Los usuarios con rol `user` solo pueden actualizar su propio perfil. Los `admin` pueden actualizar cualquier usuario.
</Note>

**URL de la petición**
```
PUT https://api.example.com/api/users/{id}
```

**Headers**

| Header | Valor | Obligatorio |
|--------|-------|-------------|
| `Authorization` | `Bearer {token}` | ✅ Sí |
| `Content-Type` | `application/json` | ✅ Sí |
| `Accept` | `application/json` | ✅ Sí |

**Parámetros de ruta (Path Parameters)**

<ParamField path="id" type="integer" required>
  ID único del usuario a actualizar.
</ParamField>

**Parámetros del cuerpo (Body Parameters)**

<ParamField body="name" type="string">
  Nombre completo del usuario. Mínimo 2 caracteres, máximo 100.
</ParamField>

<ParamField body="email" type="string">
  Nuevo correo electrónico. Debe ser único en el sistema.
</ParamField>

<ParamField body="password" type="string">
  Nueva contraseña. Mínimo 8 caracteres con letras y números.
</ParamField>

<ParamField body="role" type="string">
  Rol del usuario. Valores: `admin`, `user`. Solo modificable por administradores.
</ParamField>

<ParamField body="phone" type="string">
  Número de teléfono actualizado.
</ParamField>

<ParamField body="address" type="string">
  Dirección postal del usuario.
</ParamField>

**Cuerpo de la petición**

```json Cuerpo JSON
{
  "name": "Ana García Ruiz",
  "phone": "+34 622 333 444",
  "address": "Avenida Diagonal 100, Barcelona"
}
```

```json Respuesta
{
  "status": "success",
  "message": "Usuario actualizado correctamente",
```

**Códigos de error**

| Código | Descripción |

## DELETE /api/users/{id} — Eliminar usuario

Elimina de forma permanente un usuario del sistema. Esta acción no se puede deshacer.

<Warning>
  **Acción irreversible.** Una vez eliminado, el usuario y todos sus datos asociados se perderán permanentemente. Solo los administradores pueden realizar esta operación.
</Warning>

**URL de la petición**
```
DELETE https://api.example.com/api/users/{id}
```

**Headers**

| Header | Valor | Obligatorio |
|--------|-------|-------------|
| `Authorization` | `Bearer {token}` | ✅ Sí |
| `Accept` | `application/json` | ✅ Sí |

**Parámetros de ruta (Path Parameters)**

<ParamField path="id" type="integer" required>
  ID único del usuario a eliminar.
</ParamField>

**Respuesta exitosa — 200 OK**

**Códigos de error**

| Código | Descripción |
|--------|-------------|
| `401 Unauthorized` | Token no proporcionado o inválido |
| `403 Forbidden` | No tienes permisos para eliminar usuarios |
| `404 Not Found` | No existe un usuario con el ID proporcionado |
| `409 Conflict` | El usuario no puede eliminarse porque tiene recursos activos |
| `500 Internal Server Error` | Error interno del servidor |

```php DELETE /api/users/{id} — PHP
<?php

$token  = 'tu_token_aqui';
$userId = 42;
```

```javascript DELETE /api/users/{id} — JavaScript
const token  = 'tu_token_aqui';
const userId = 42;

const response = await fetch(
  `https://api.example.com/api/users/${userId}`,
  {
    method: 'DELETE',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Accept':        'application/json',
    },
  }
);

if (!response.ok) {
  const error = await response.json();
  throw new Error(error.message);
}

const data = await response.json();
console.log(data);
```

```python DELETE /api/users/{id} — Python
import requests

token   = 'tu_token_aqui'
user_id = 42

headers = {
    'Authorization': f'Bearer {token}',
    'Accept': 'application/json',
}

response = requests.delete(
    f'https://api.example.com/api/users/{user_id}',
    headers=headers,
)

response.raise_for_status()
data = response.json()
print(data)
```
