## GET /api/users — List Users

Returns the full list of registered users. Supports pagination via query parameters.

<Note>
  **Authentication required.** Include your Bearer token in the `Authorization` header.
</Note>

**Request URL**
```
GET https://api.example.com/api/users
```

**Headers**

| Header | Value | Required |
|--------|-------|----------|
| `Authorization` | `Bearer {token}` | ✅ Yes |
| `Accept` | `application/json` | ✅ Yes |

**Query Parameters**

<ParamField query="page" type="integer">
  Page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer">
  Number of results per page. Defaults to `15`. Maximum: `100`.
</ParamField>

<ParamField query="search" type="string">
  Filter users by name or email address.
</ParamField>

**Success Response — 200 OK**

```json Response
{
  "status": "success",
  "data": [
    {
      "id": 1,
      "name": "Ana García",
      "email": "ana.garcia@example.com",
      "role": "admin",
      "created_at": "2024-01-15T10:30:00Z"
    },
    {
      "id": 2,
      "name": "Carlos López",
      "email": "carlos.lopez@example.com",
      "role": "user",
      "created_at": "2024-02-20T14:45:00Z"
    }
  ],
  "pagination": {
    "current_page": 1,
    "per_page": 15,
    "total": 87,
    "last_page": 6
  }
}
```

**Error Codes**

| Code | Description |
|------|-------------|
| `401 Unauthorized` | Token not provided or invalid |
| `403 Forbidden` | You do not have permission to list users |
| `500 Internal Server Error` | Internal server error |

**Code Examples**

<CodeGroup>

```php GET /api/users — PHP
<?php

$token = 'your_bearer_token';

$ch = curl_init();
curl_setopt_array($ch, [
    CURLOPT_URL            => 'https://api.example.com/api/users?page=1&per_page=15',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => [
        'Authorization: Bearer ' . $token,
        'Accept: application/json',
    ],
]);

$response = curl_exec($ch);
$statusCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

$data = json_decode($response, true);
print_r($data);
```

```javascript GET /api/users — JavaScript
const token = 'your_bearer_token';

const response = await fetch(
  'https://api.example.com/api/users?page=1&per_page=15',
  {
    method: 'GET',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Accept': 'application/json',
    },
  }
);

if (!response.ok) {
  throw new Error(`HTTP error: ${response.status}`);
}

const data = await response.json();
console.log(data);
```

```python GET /api/users — Python
import requests

token = 'your_bearer_token'

headers = {
    'Authorization': f'Bearer {token}',
    'Accept': 'application/json',
}

params = {
    'page': 1,
    'per_page': 15,
}

response = requests.get(
    'https://api.example.com/api/users',
    headers=headers,
    params=params,
)

response.raise_for_status()
data = response.json()
print(data)
```

```bash GET /api/users — cURL
curl -X GET \
  'https://api.example.com/api/users?page=1&per_page=15' \
  -H 'Authorization: Bearer your_bearer_token' \
  -H 'Accept: application/json'
```

## POST /api/users — Create User

Creates a new user in the system. Returns the created user object with its assigned ID.

<Note>
  **Authentication required.** Only users with the `admin` role can create new users.
</Note>

**Request URL**
```
POST https://api.example.com/api/users
```

**Headers**

| Header | Value | Required |
|--------|-------|----------|
| `Authorization` | `Bearer {token}` | ✅ Yes |
| `Content-Type` | `application/json` | ✅ Yes |
| `Accept` | `application/json` | ✅ Yes |

**Body Parameters**

<ParamField body="name" type="string" required>
  Full name of the user. Minimum 2 characters, maximum 100.
</ParamField>

<ParamField body="email" type="string" required>
  Unique email address for the user. Must be a valid email format.
</ParamField>

<ParamField body="password" type="string" required>
  User password. Minimum 8 characters. Must include letters and numbers.
</ParamField>

<ParamField body="role" type="string">
  User role. Accepted values: `admin`, `user`. Defaults to `user`.
</ParamField>

<ParamField body="phone" type="string">
  User phone number. Example format: `+1 800 555 0100`.
</ParamField>

**Request Body**

```json JSON Body
{
  "name": "Maria Fernandez",
  "email": "maria.fernandez@example.com",
  "password": "SecurePass123",
  "role": "user",
  "phone": "+1 800 555 0100"
}
```

**Success Response — 201 Created**

```json Response
{
  "status": "success",
  "message": "User created successfully",
  "data": {
    "id": 42,
    "name": "Maria Fernandez",
    "email": "maria.fernandez@example.com",
    "role": "user",
    "phone": "+1 800 555 0100",
    "created_at": "2024-04-10T12:00:00Z"
  }
}
```

**Error Codes**

| Code | Description |
|------|-------------|
| `400 Bad Request` | Invalid or incomplete data in the request body |
| `401 Unauthorized` | Token not provided or invalid |
| `403 Forbidden` | You do not have permission to create users |
| `409 Conflict` | A user with that email address already exists |
| `422 Unprocessable Entity` | Validation error on one or more fields |
| `500 Internal Server Error` | Internal server error |

**Code Examples**

<CodeGroup>

```php POST /api/users — PHP
<?php

$token = 'your_bearer_token';

$body = [
    'name'     => 'Maria Fernandez',
    'email'    => 'maria.fernandez@example.com',
    'password' => 'SecurePass123',
    'role'     => 'user',
    'phone'    => '+1 800 555 0100',
];

$ch = curl_init();
curl_setopt_array($ch, [
    CURLOPT_URL            => 'https://api.example.com/api/users',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST           => true,
    CURLOPT_POSTFIELDS     => json_encode($body),
    CURLOPT_HTTPHEADER     => [
        'Authorization: Bearer ' . $token,
        'Content-Type: application/json',
        'Accept: application/json',
    ],
]);

$response = curl_exec($ch);
$statusCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

$data = json_decode($response, true);
print_r($data);
```

```javascript POST /api/users — JavaScript
const token = 'your_bearer_token';

const body = {
  name:     'Maria Fernandez',
  email:    'maria.fernandez@example.com',
  password: 'SecurePass123',
  role:     'user',
  phone:    '+1 800 555 0100',
};

    'Authorization': `Bearer ${token}`,

  },

});

if (!response.ok) {
  const error = await response.json();
  throw new Error(error.message);
}

const data = await response.json();
console.log(data);
```

```python POST /api/users — Python
    'https://api.example.com/api/users',

```

## POST /api/auth/login — Authenticate

</Info>

**Request URL**


**Headers**

|--------|-------|----------|
| `Content-Type` | `application/json` | ✅ Yes |
| `Accept` | `application/json` | ✅ Yes |

**Body Parameters**

<ParamField body="email" type="string" required>
  Email address of the registered user.
</ParamField>

<ParamField body="password" type="string" required>
  Password of the user account.
</ParamField>

**Request Body**


## PUT /api/users/{id} — Update User

Updates an existing user's data. You can send only the fields you want to modify (partial update).

<Note>
  **Authentication required.** Users with the `user` role can only update their own profile. `admin` users can update any account.
</Note>

**Request URL**
```
PUT https://api.example.com/api/users/{id}
```

**Headers**

| Header | Value | Required |
|--------|-------|----------|
| `Authorization` | `Bearer {token}` | ✅ Yes |
| `Content-Type` | `application/json` | ✅ Yes |
| `Accept` | `application/json` | ✅ Yes |

**Path Parameters**

<ParamField path="id" type="integer" required>
  Unique ID of the user to update.
</ParamField>

**Body Parameters**

<ParamField body="name" type="string">
  Full name of the user. Minimum 2 characters, maximum 100.
</ParamField>

<ParamField body="email" type="string">
  New email address. Must be unique across all accounts.
</ParamField>

<ParamField body="password" type="string">
  New password. Minimum 8 characters with letters and numbers.
</ParamField>

<ParamField body="role" type="string">
  User role. Accepted values: `admin`, `user`. Only modifiable by administrators.
</ParamField>

<ParamField body="phone" type="string">
  Updated phone number.
</ParamField>

<ParamField body="address" type="string">
  Postal address of the user.
</ParamField>

**Request Body**

```json JSON Body
{
  "name": "Ana Garcia Ruiz",
  "phone": "+1 800 555 0200",
  "address": "500 Main Street, New York, NY 10001"
}
```

**Success Response — 200 OK**

```json Response
{
  "status": "success",
  "message": "User updated successfully",
  "data": {
    "id": 1,
    "name": "Ana Garcia Ruiz",
    "email": "ana.garcia@example.com",
    "role": "admin",
    "phone": "+1 800 555 0200",
    "address": "500 Main Street, New York, NY 10001",
    "created_at": "2024-01-15T10:30:00Z",
    "updated_at": "2024-04-10T15:20:00Z"
  }
}
```

**Error Codes**

| Code | Description |
|------|-------------|
| `400 Bad Request` | Invalid data in the request body |
| `401 Unauthorized` | Token not provided or invalid |
| `403 Forbidden` | You do not have permission to modify this user |
| `404 Not Found` | No user exists with the provided ID |
| `409 Conflict` | The new email address is already in use |
| `422 Unprocessable Entity` | Validation error on one or more fields |
| `500 Internal Server Error` | Internal server error |

## DELETE /api/users/{id} — Delete User

Permanently deletes a user from the system. This action cannot be undone.

<Warning>
  **Irreversible action.** Once deleted, the user and all associated data are permanently lost. Only administrators can perform this operation.
</Warning>

**Request URL**
```
DELETE https://api.example.com/api/users/{id}
```

**Headers**

| Header | Value | Required |
|--------|-------|----------|
| `Authorization` | `Bearer {token}` | ✅ Yes |
| `Accept` | `application/json` | ✅ Yes |

**Path Parameters**

<ParamField path="id" type="integer" required>
  Unique ID of the user to delete.
</ParamField>

**Success Response — 200 OK**

```json Response
{
  "status": "success",
  "message": "User deleted successfully",
  "data": {
    "id": 42,
    "deleted_at": "2024-04-10T16:30:00Z"
  }
}
```

**Error Codes**

| Code | Description |
|------|-------------|
| `401 Unauthorized` | Token not provided or invalid |
| `403 Forbidden` | You do not have permission to delete users |
| `404 Not Found` | No user exists with the provided ID |
| `409 Conflict` | The user cannot be deleted because they have active resources |
| `500 Internal Server Error` | Internal server error |
